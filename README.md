# Streamer Arena - Realistic Games Update

Esta actualización añade juegos más jugables y visuales:

- Las 40 con mesa por turnos y baza visible
- Ajedrez para 2 jugadores
- Parchís simplificado pero jugable
- Carrera de coches por turnos con turbo y boxes
- Librería de juegos ampliada

## Cómo actualizar

Sustituye en tu repositorio estos archivos:

- index.html
- styles.css
- app.js

No toques `firebase-config.js`.
